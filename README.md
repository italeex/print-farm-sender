# Printer Farm Sender

Десктопное приложение (Python 3.13 + Tkinter, стандартная библиотека + `requests`) для одновременной рассылки одного или нескольких `.gcode` файлов на другие принтеры Creality (протокол Moonraker Klipper) с прогрессом по каждому принтеру.

## Запуск

- `python print_farm_sender.py` — или двойной клик по `Запустить.bat` (без консольного окна).
- при первом запуске список принтеров берется из последнего по времени файла `deviceInfo.json` в каталоге Creality Print на этой машине.
- затем нажмите `Проверить связь` (online/offline) и `Отправить`. Отправки можно отменить, список принтеров редактируется через `Принтеры...`.

## Ограничения версии 1

- Прогресс и скорость отражают скорость чтения файла/подготовку тела запроса, а не передачу по сети: полоса может достигать 100% до фактического завершения передачи и оставаться после завершения отправки (платеж urllib3 2.x материализует тело запроса).
- `Отмена` не прерывает текущий HTTP-запрос — она гарантирует остановку до начала передачи новых файлов.
- Пиковая память ≈ сумма размеров всех одновременно отправляемых файлов (по одному телу запроса на принтер). При 25 принтерах и одном файле 200 МБ потребление может достигать ~5 ГБ.
- Отправка только загрузки: `POST /server/files/upload` с `root=gcodes`; автозапуск печати не поддерживается.

## Проверка

`python -m unittest discover -s tests -v` — 23 теста (все фиктивные серверы на 127.0.0.1, реальные принтеры не задействованы).
