# Printer Farm Dashboard

Локальный веб-дашборд фермы принтеров Creality K2 Plus (Moonraker/Klipper). Показывает состояние всех машин на одном экране, позволяет управлять печатью и отправлять `.gcode` на выбранные принтеры. Заменяет прежнюю Tkinter-версию: её код остался в истории git.

Приложение работает как локальный HTTP-сервер на Python 3.13. Зависимости: стандартная библиотека и `requests`. Новых пакетов нет.

## Возможности

- **Карточки принтеров** в адаптивной сетке: имя, `host:port`, статус, текущий файл, прогресс, слой `N/M`, ETA, температуры сопла и стола, тип филамента.
- **Статусы**: «Печатает», «Пауза», «Свободен», «Ошибка», «Не в сети». Сводка по ферме и время до ближайшего финиша.
- **Превью модели** из PNG-миниатюры, встроенной в gcode. Для печатающего или последнего файла — по HTTP Range с принтера, для локального файла — с диска.
- **Детали из gcode**: парсинг `EXCLUDE_OBJECT_DEFINE`, на карточке показывается имя и количество экземпляров (например, «Крышка ×35»). Основа для будущего планирования графика печати.
- **Ошибки Creality** с кодом, понятным названием, подробностями и подсказкой. Коды `AC/AL/FR/FS/FB/FO/TE/TR/TC/TF/XS/XD` и числовые, разбор `klippy.log` и текстовый fallback; ссылка на вики Creality.
- **Mainsail / Fluidd** — дашборд сам определяет, какая веб-оболочка стоит на принтере (по HTML на порту 4408), и подписывает кнопку «Mainsail», «Fluidd» или «Интерфейс».
- **Сканирование сети** — поиск Moonraker-принтеров в локальной подсети (по умолчанию /24, можно задать свою), определение UI, добавление выбранных одним действием и повторный скан.
- **Камера** — кнопка на каждой карточке открывает `http://<ip>:8000/`. Поток зависит от прошивки принтера: на части K2 Plus локальная камера сейчас не отдаёт кадры.
- **Управление печатью**: пауза, продолжение, отмена текущей печати. Отмена — с подтверждением. Те же действия доступны массово для выбранных принтеров.
- **Переименование**: пункт на карточке и массовое переименование по шаблону `{n}`, `{ip}`, `{name}`, `{host}` (например, `K2-{n}`).
- **Отправка файлов**: один или несколько `.gcode` на выбранные принтеры, параллельно, с прогрессом по каждому принтеру, общим прогрессом и отменой очереди.
- **Файловый браузер**: диски, папки и `.gcode`-файлы, превью выбранного файла, запоминание последнего каталога. Кнопка «Обзор…» открывает системный диалог Windows — файлы не копируются.
- **Поиск и фильтры** по имени, адресу и файлу; кликабельные плитки сводки, «Выбрать видимые», «Выбрать онлайн», «Снять выбор», группировка по статусу, компактный режим и журнал событий.
- **ETA**: остаток и время окончания из `end_time` Moonraker/Mainsail; при отсутствии — расчёт по `estimated_time` или прогрессу.
- **История состояний**: SQLite-журнал переходов (печать, пауза, завершение, ошибка, offline), время завершения и количество деталей. На карточке — «История» с таймлайном за 24 часа / 7 дней / 30 дней и списком событий.
- **Планы по деталям**: цели на день, неделю и месяц по каждой детали, прогресс из завершённых печатей, отдельно — часы печати. Импорт недельного плана из Excel или JSON.

## Запуск

Требования: Windows, Python 3.13, установленный `requests`.

- Двойной клик по `Запустить.bat` — запускает `pythonw farm_server.py` без консольного окна. Если `pythonw` не найден, используется `python farm_server.py` с консолью.
- Либо вручную: `python farm_server.py`.

Сервер слушает только `127.0.0.1`. Первый свободный порт из диапазона 8765–8775: обычно <http://127.0.0.1:8765/>. Фактический адрес пишется в `farm.log`, браузер открывается автоматически. Если дашборд уже запущен, повторный запуск открывает существующую вкладку и завершается.

Остановка: закрыть вкладку — сервер завершится сам после 10 минут без heartbeat и без активной отправки; либо `Ctrl+C` в консольном режиме.

## Интерфейс

Сверху — шапка с числом принтеров, индикатором сервера и кнопками «Обновить», «Сканировать сеть», «План», «Принтеры», «Компактно», «Журнал». Ниже сводка: печатают, на паузе, свободны, ошибки, не в сети, до ближайшего финиша; плитки кликабельны и фильтруют карточки. Затем поиск, фильтры-чипы, массовые действия (пауза, продолжение, стоп, переименование) и кнопки отправки. Переключатель «Группировать» раскладывает карточки по статусам с заголовками групп. Лоток показывает выбранные файлы и число отправок. Основная область — карточки принтеров, снизу выдвигается журнал. Модальные окна: выбор файлов, сканирование сети, план, история принтера, менеджер принтеров, переименование, детали ошибки, подтверждение действия.

Карточки обновляются точечно, без перерисовки страницы: не сбрасываются фокус, выделение и прокрутка. Данные сервера опрашиваются каждые 2 с, во время отправки — каждые 1 с.

Горячие клавиши: `/` — поиск, `Ctrl+Enter` — отправить, `Esc` — закрыть окно, `C` — компактный режим, `J` — журнал.

## История и планы

- **История принтера**: на карточке меню «•••» → «История». Показывает текущее состояние, последнее завершение (файл, время, длительность, детали), таймлайн за 24 часа / 7 дней / 30 дней и список событий (печать, пауза, продолжение, завершение, ошибка, offline). Незавершённые и отменённые печати не засчитываются как выполненные.
- **План по деталям**: кнопка «План» в шапке. Таблица «деталь / план / факт / остаток / %» на день, неделю и месяц; факт — из завершённых печатей, часы печати — отдельной целью. Цели и факты хранятся в SQLite `farm_history.db`.
- **Импорт плана**: кнопка «Импорт плана…» в окне плана. Поддерживается ваш Excel «План график» (лист с `Номенклатура`, строки `план`/`факт`, даты во второй строке, количества по дням) и JSON. Колонка C с накопительным итогом игнорируется, факт из Excel не импортируется — факт считается по истории печати.
- История хранится 180 дней и переживает перезапуск. Файл базы не входит в git.

Формат JSON для ручного импорта:

```json
{
  "week_start": "2026-10-26",
  "items": [
    {"date": "2026-10-26", "code": "МВСЛ.ГР3.01.42000.01", "name": "Крышка", "target": 20}
  ]
}
```

Сопоставление с gcode идёт по обозначению детали: `МВСЛ`/`МФСЛ`, пробелы, `_` и `.stl` не важны. Поэтому `МВСЛ.ГР3.01.42000.01 Крышка` и `МФСЛ.ГР3.01.42000.01_Крышка.stl` — одна деталь.

## Файловый браузер

Кнопка «Выбрать файлы…» открывает диски и папки. Показываются только каталоги и файлы `.gcode`; файлы других типов скрыты. Для выбранного файла показывается встроенное превью. Кнопка «Обзор…» открывает системный диалог Windows (Tk-подпроцесс) и возвращает абсолютные пути без копирования файлов. Каталог последней отправки сохраняется в конфигурации. Ошибки доступа показываются уведомлением, а не роняют дашборд.

## Конфигурация

`printers.json` создаётся рядом с `farm_server.py` при первом запуске. Если файла нет, список принтеров берётся из самого свежего `deviceInfo.json` в `%APPDATA%\Creality\Creality Print\*\`. Принтеры можно добавлять, изменять и удалять через кнопку «Принтеры» — изменения сразу пишутся в файл атомарно.

При первом заполнении имя собирается как `model` + последний октет IP: `F008` — код модели K2 Plus из `deviceInfo.json`, `110` — последний октет адреса. Имя можно изменить на карточке (меню «•••» → «Переименовать») или массово по шаблону; ключом принтера остаётся `host:port`.

```json
{
  "printers": [
    {"name": "F008 100", "host": "192.168.7.100", "port": 7125, "mainsail_port": 4408}
  ],
  "last_dir": "C:\\gcode",
  "window": {"width": 1180, "height": 760},
  "refresh_seconds": 5
}
```

- `port` — порт Moonraker, по умолчанию 7125.
- `mainsail_port` — порт Mainsail, по умолчанию 4408. Старые файлы без этого поля читаются без миграции.
- `refresh_seconds` — интервал опроса принтеров, 2–30, по умолчанию 5. При недоступности принтера интервал растёт до 60 с.
- `window` сохранён для обратной совместимости и веб-интерфейсом не используется.

Повреждённый `printers.json` переименовывается в `printers.json.broken`, приложение стартует с пустым списком и пишет предупреждение в журнал.

`farm.log` — журнал приложения с ротацией: 1 МБ, 3 архивных файла.

## HTTP API

Сервер `ThreadingHTTPServer`, только `127.0.0.1`, без CORS для внешних источников. Изменяющие запросы проверяют `Origin`; API, принимающее данные, требует `Content-Type: application/json`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | страница дашборда |
| GET | `/api/state` | принтеры, сводка, состояние отправки, конфигурация |
| GET | `/api/thumb/<key>` | PNG-превью печати принтера |
| GET | `/api/files/thumb?path=` | PNG-превью локального файла |
| GET | `/api/fs?path=` | диски, папки и `.gcode`-файлы |
| POST | `/api/fs/browse` | системный диалог выбора `.gcode` (Tk-подпроцесс) |
| POST | `/api/scan` | поиск принтеров в подсети `{subnet?}` |
| GET | `/api/history/<key>` | события и таймлайн принтера за период |
| GET/POST | `/api/plan` | цели на день/неделю/месяц и прогресс |
| POST | `/api/plan/import` | импорт плана из Excel/JSON `{path}` |
| GET | `/api/journal?since=` | события журнала (до 200) |
| POST | `/api/send` | запуск отправки `{printers, files}` |
| POST | `/api/job/cancel` | отмена очереди отправки |
| POST | `/api/print/<key>/pause\|resume\|cancel` | управление печатью |
| GET/POST | `/api/printers` | список и добавление принтеров |
| POST | `/api/printers/rename` | массовое переименование `{updates}` |
| POST | `/api/printers/import` | добавление выбранных после сканирования `{printers}` |
| PUT/DELETE | `/api/printers/<key>` | изменение и удаление принтера |
| POST | `/api/heartbeat` | продление работы сервера |
| POST | `/api/shutdown` | корректная остановка |

## Архитектура

```
farm_core.py      конфигурация, клиент Moonraker, отправка, BatchSender
farm_monitor.py   опрос статусов, offline-бэкофф, модель состояния
farm_errors.py    таблица кодов Creality и разбор ошибок Klipper
farm_thumbs.py    извлечение PNG-миниатюр из gcode
farm_jobs.py      состояние задачи отправки
farm_server.py    HTTP API, статика, журнал, точка входа
web/              index.html, styles.css, app.js
tests/            unittest + fake Moonraker на 127.0.0.1
```

## Проверка

```shell
python -m unittest discover -s tests -v
python -m py_compile farm_core.py farm_errors.py farm_thumbs.py farm_monitor.py farm_jobs.py farm_server.py
```

252 теста. Все сетевые тесты используют fake Moonraker на `127.0.0.1` с эфемерным портом; реальные принтеры не задействованы.

## Ограничения

- **Камеры нет.** K2 Plus не отдаёт видеопоток; вместо кадра — превью модели из gcode. Место под камеру в интерфейсе не занято.
- **Только загрузка.** Файл копируется в `gcodes` принтера; автозапуск печати после загрузки не поддерживается.
- **Прогресс отправки отражает чтение файла с диска**, а не передачу по сети: `requests`/urllib3 материализует тело multipart-запроса, поэтому полоса может дойти до 100% до фактического завершения передачи. «Отмена» останавливает очередь и следующие файлы, но не прерывает уже отправляемый POST.
- **Память.** Пиковая нагрузка при отправке ≈ сумма размеров одновременно отправляемых файлов, по одному телу запроса на принтер.
- **Только локальный доступ.** Сервер слушает `127.0.0.1`; удалённого доступа, HTTPS и авторизации нет. Защита от CSRF ограничена проверкой `Origin` и JSON-типа; запускать на общей машине с недоверенными пользователями не следует.
- **Превью только встроенные.** Если в gcode нет PNG-миниатюры, показывается заглушка.
- **Состояние с задержкой.** Статус обновляется не чаще `refresh_seconds`; недоступный принтер опрашивается с backoff до 60 с.
- **Одна задача отправки.** Параллельно можно отправить файлы на много принтеров, но второй job одновременно не запускается; очереди между задачами нет.
- **Вне scope:** CFS и управление филаментом, калибровки, прошивки, Creality Cloud, светлая тема, другие языки, мобильное приложение.
